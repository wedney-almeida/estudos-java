<h2>▶️ Como executar os exercícios</h2>

<ol>
  <li>Clone o repositório:
    <pre>git clone https://github.com/wedney-almeida/estudos-java.git</pre>
  </li>
  <li>No Eclipse, use <b>File &gt; Import &gt; Existing Projects into Workspace</b> e selecione a pasta do projeto.</li>
  <li>Abra o arquivo desejado em <code>src/</code> e execute com <b>Run As &gt; Java Application</b>.</li>
</ol>

<p>É necessário ter o <b>JDK 21</b> instalado.</p>
